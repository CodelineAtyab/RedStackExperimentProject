# WeatherStation

A small Java console program that demonstrates converting a Celsius temperature to Fahrenheit and Kelvin.

## Run

From this folder, compile and start the program with Java 17 or later:

```bash
javac WeatherStation.java
java WeatherStation
```

The program prompts for a Celsius temperature. Currently, the entered value is not used: the conversions use the `currentCelsius` field, which is initialized to `25.0`.
