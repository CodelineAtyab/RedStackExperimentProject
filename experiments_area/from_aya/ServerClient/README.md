## About
This project has two parts:
- **Server:** Sends profile data as JSON
- **Client:** Gets the JSON data and prints it

## Requirements
- Java 17
- Maven
- Spring Boot
- Unirest

## How to Run
1. Run the server
2. Set the server IP and port in the client
3. Run the client
4. Check the output
