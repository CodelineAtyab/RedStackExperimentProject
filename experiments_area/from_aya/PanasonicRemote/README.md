# PanasonicRemote

## JDK Version
OpenJDK 17.0.20.1 (Amazon Corretto), 64-bit

## Compile and Run
Compile: `javac PanasonicRemote.java`
Run: `java PanasonicRemote`

## Compilation Output
The compiler(`javac`)--> creates `PanasonicRemote.class` in the same folder.

## JVM Pipeline
The `javac` -->compiler converts Java code into --> bytecode (`.class`). 
The `JVM`--> loads and runs the bytecode. 
The `JIT`--> compiler converts frequently used code into native machine code to improve performance.
