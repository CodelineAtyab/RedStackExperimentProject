Panasonic Remote

A simple Java program that simulates a Panasonic remote control.

JDK Version: Oracle JDK 27 (27+35-2325)

How to Run:
    1-Compile the program 
        javac PanasonicRemote.java
    2-Run the program:
        java PanasonicRemote

JVM Pipeline:
    1- Write the source code in PanasonicRemote.java
    2- javac compiles the code into bytecode
    3- The bytecode is saved in PanasonicRemote.class
    4- The JVM loads and runs the bytecode 
    5- The JIT converts frequently used code into machine code to help it run faster
