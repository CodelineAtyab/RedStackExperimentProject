# WeatherDesk

A small Java console application that converts a temperature entered in Celsius to Fahrenheit and Kelvin.

## Requirements

- Java Development Kit (JDK) installed and available on your `PATH`

## Run

Open a terminal in this directory and compile both source files:

```powershell
javac TemperatureConverter.java WeatherStation.java
```

Start the application:

```powershell
java TemperatureConverter
```

Enter a temperature in Celsius when prompted. The program prints the equivalent Fahrenheit and Kelvin values.
