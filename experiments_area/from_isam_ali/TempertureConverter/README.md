# TempertureConverter

A small Java console program that reads a temperature in Celsius and converts it to Fahrenheit and Kelvin.

## Run

From this folder, compile and start the program with Java 17 or later:

```bash
javac TempertureConverter.java
java TempertureConverter
```

Enter a numeric Celsius temperature when prompted. The program prints the equivalent Fahrenheit and Kelvin values.
