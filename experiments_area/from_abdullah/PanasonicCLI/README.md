# Panasonic AC Remote CLI

A small Java console program that simulates a Panasonic air-conditioner remote. Use the menu to turn the AC on or off, check its current temperature, or exit.

## Requirements

- Java Development Kit (JDK) installed and available on your `PATH`

## Run

Open a terminal in this directory and compile the program:

```powershell
javac PanasonicRemote.java
```

Run it with:

```powershell
java PanasonicRemote
```

Choose an option from the menu by entering `1`, `2`, `3`, or `4`.

## Menu

| Option | Action |
| --- | --- |
| 1 | Turn the AC on |
| 2 | Turn the AC off |
| 3 | Display the current temperature (24 C) |
| 4 | Exit the program |
