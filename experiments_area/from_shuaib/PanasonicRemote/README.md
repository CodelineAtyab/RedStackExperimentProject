# Panasonic Remote

A small Java console program that simulates a basic air-conditioner remote.

## Features

- Turn the simulated AC on or off and display the remote status.
- Display the current temperature, initially set to 24°C.
- Exit the menu.

The temperature is fixed in this example; the program does not change it or control physical hardware.

## Run

From this directory, compile and start the program with Java 17:

```sh
javac --release 17 PanasonicRemote.java
java PanasonicRemote
```

Choose an option from the menu. Select `4` to exit.
