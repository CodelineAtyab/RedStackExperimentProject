# Support Center Ticket Queue CLI

## Overview

A Java command-line application that manages customer support tickets using a queue.

## Features

- Add normal tickets to the end of the queue.
- Add urgent tickets to the front of the queue.
- Serve the next waiting ticket.
- View all waiting tickets without removing them.
- Display a numbered menu for user interaction.

## Concepts Practised

- ArrayList
- Queue
- LinkedList
- Scanner
- Indexed for loops
- Nested for loops
- Conditional statements
- Integer.parseInt()
- String.length()

## How to Run

Compile:

    javac SupportCenterTicketQueue.java

Run:

    java SupportCenterTicketQueue

## Example

The program allows users to add normal and urgent tickets, view the waiting queue, and serve tickets in priority order.
