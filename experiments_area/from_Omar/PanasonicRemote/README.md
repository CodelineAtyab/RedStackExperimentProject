# PanasonicRemote

This project lives in the project root for the PanasonicRemote folder.

## JDK version

Amazon Corretto JDK 17.0.20.12.1 (javac 17.0.20.1)

## Run from the terminal

From the project root, run:

```bash
javac PanasonicRemote.java
java PanasonicRemote
```

No IDE steps are needed to run this program.
