# Customer Feedback Portal — HashMap Practice

## Overview

This exercise practises Java `HashMap` and nested `HashMap` structures for storing and retrieving customer feedback.

## Files

- `FeedbackLookup.java` — Uses a `HashMap` to store and retrieve customer feedback by customer ID.
- `FeedbackPortal.java` — Uses a nested `HashMap` to store customer details, including names and feedback.

## Concepts Practised

- `HashMap`
- `put()` to store entries
- `get()` to retrieve entries
- Nested `HashMap` structures

## How to Run

Compile the Java files:

    javac FeedbackLookup.java FeedbackPortal.java

Run the basic lookup example:

    java FeedbackLookup

Run the nested map example:

    java FeedbackPortal
