# Feedback Portal

This folder contains three small Java console programs demonstrating ways to
represent and display customer feedback:

- **`FeedbackComments`** stores sample feedback comments in a list, prints the
  third comment, and displays the comments.
- **`FeedbackRating`** associates sample customer names with ratings and prints
  each customer and their rating.
- **`FeedbackScoreTable`** stores scores in a two-dimensional array and prints
  the score table.

## Requirements

- Java Development Kit (JDK) installed and available on your `PATH`

## Compile and run

Open a terminal in this folder, then compile the programs:

```sh
javac FeedbackComments.java FeedbackRating.java FeedbackScoreTable.java
```

Run any program by its class name:

```sh
java FeedbackComments
java FeedbackRating
java FeedbackScoreTable
```

Each program has its own `main` method and can be run independently.
