# Warmup 1 Exercises

This folder contains solutions to these CodingBat Java Warmup-1 exercises:

| Exercise | What it does |
| `hasTeen` | Checks whether any of three numbers is in the teen range (13–19). |
| `sumDouble` | Returns the sum of two numbers, doubling it when the numbers are equal. |
| `startHi` | Checks whether a string starts with `"hi"`. |
| `missingChar` | Returns a string with the character at the specified index removed. |
| `diff21` | Returns the difference from 21, doubled when the number is greater than 21. |
| `close10` | Returns whichever of two numbers is closer to 10, or `0` if they are equally close. |

The helper method `getSubtractionResult` calculates the absolute difference between two numbers and is used by `close10`.

## Compile and run

From this directory, compile with Java 17 and run the included examples:

```sh
javac --release 17 Warmup1.java
java Warmup1
```
