# Bracket Validator

## Description

A Java command-line program that checks whether expressions contain balanced parentheses and curly brackets.

## Features

- Accepts multiple expressions from the user.
- Uses a Deque as a stack.
- Checks matching opening and closing brackets.
- Detects unmatched and incorrectly ordered brackets.
- Ignores characters that are not brackets.

## Concepts Practiced

- Scanner
- Deque and LinkedList
- Stack operations: push, peek, pop, isEmpty
- For loops
- If/else conditions
- Boolean variables
- String and character methods

## How to Run

Compile the program:

```bash
javac BracketValidator.java
```

Run it:

```bash
java BracketValidator
```
