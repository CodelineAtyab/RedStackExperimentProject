# Customer Feedback Portal Exercises

This folder contains three small Java console examples for storing and displaying customer feedback data.

## Files

| File | Description |
|---|---|
| `FeedbackRatings.java` | Associates three customer names with ratings and prints each customer and rating. |
| `FeedbackScoreTable.java` | Fills and prints a 3×3 table of feedback scores. |
| `FeedbackComments.java` | Stores sample feedback comments in a list and prints them using both a for-each loop and an index-based loop. |

## Compile and run

From this directory, compile the files with Java 17:

```sh
javac --release 17 FeedbackRatings.java FeedbackScoreTable.java FeedbackComments.java
```

Run an example by specifying its class name:

```sh
java FeedbackRatings
java FeedbackScoreTable
java FeedbackComments
```
