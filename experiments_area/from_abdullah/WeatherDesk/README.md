# Weather Desk Converter

JDK used: Amazon Corretto 17.0.20.1 LTS

## TemperatureConverter

Compile and run from this folder:

```powershell
javac TemperatureConverter.java
java TemperatureConverter
```

## WeatherStation

Compile and run from this folder:

```powershell
javac WeatherStation.java
java WeatherStation
```

## Java compilation pipeline

The `javac` compiler translates a `.java` source file into byte-code stored in a `.class` file. The JVM loads and runs that byte-code. The JIT compiler translates frequently used sections of byte-code into native machine code while the program runs.
