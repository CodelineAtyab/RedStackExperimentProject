# Weather Station

This project contains a simple Java weather application that converts temperatures and displays weather information.

## Files

- `TemperatureConverter.java` - Converts temperatures between Celsius and Fahrenheit.
- `WeatherStation.java` - Stores and displays weather data for a station.

## How to run

From this folder, compile the Java files:

```bash
javac TemperatureConverter.java WeatherStation.java
```

Then run the main program:

```bash
java WeatherStation
```

If you want to run the converter directly:

```bash
java TemperatureConverter
```

## Notes

This is a small Java practice project focused on basic class design, temperature conversion, and weather station logic.
