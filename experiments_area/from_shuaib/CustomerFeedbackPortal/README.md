# Customer Feedback Portal

Small Java exercises that represent customer feedback using ratings, comments, and a score table. Each class has its own `main` method and can be run independently.

## Programs

- **`FeedbackRatings`** pairs three customer names with integer ratings and prints each customer and rating.
- **`FeedbackComments`** stores sample comments in a list, prints the third comment, and displays all comments with both a for-each loop and an index-based loop.
- **`FeedbackScoreTable`** fills and prints a 3-by-3 integer score table.

## Requirements

- Java Development Kit (JDK) 17

## Compile and run

From this folder, compile the Java source files:

```powershell
javac --release 17 *.java
```

Run any program by its class name:

```powershell
java FeedbackRatings
java FeedbackComments
java FeedbackScoreTable
```
