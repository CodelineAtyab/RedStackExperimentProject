# Customer Feedback Portal

## Overview

A Java command-line application that collects, displays, searches, and manages customer feedback.

## Features

- Submit customer feedback.
- Validate customer names and product names.
- Validate ratings from 1 to 5.
- View all submitted feedback.
- Generate rating reports.
- Search feedback by product using HashMap.
- Save feedback to a text file.
- Load saved feedback when the application starts.

## Technologies

- Java
- ArrayList
- HashMap
- 2D Arrays
- File Handling
- Scanner

## How to Run

Compile:

    javac CustomerFeedbackPortal.java

Run:

    java CustomerFeedbackPortal
