# Panasonic Remote

This project lives in the project root and can be run directly from the command line.

## JVM and JIT

Java code is compiled into bytecode and run by the Java Virtual Machine (JVM). The JVM lets the same Java program run on different operating systems. The JIT compiler improves performance by optimizing frequently used code while the program runs.

## JDK version

The project uses Java 17.

## Run from the project root

```bash
javac PanasonicRemote.java
java PanasonicRemote
```

No IDE steps are needed to run this project.
