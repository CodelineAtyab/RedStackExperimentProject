# Solved Exercises
Exercises implemented in `WarmUpOne.java`:

- `sleepIn` — determine whether sleeping in is allowed.
- `monkeyTrouble` — check whether both monkeys smile or neither does.
- `sumDouble` — double the sum when both numbers are equal.
- `diff21` — calculate the difference from 21, doubled when above 21.
- `parrotTrouble` — check whether a talking parrot is causing trouble.
- `makes10` — check whether either number or their sum is 10.
